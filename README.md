# Голосовой синтезатор без ИИ

Синтезатор русской речи с интонацией, который работает прямо в браузере, без нейросетей, серверов и интернета.
В нём 5 готовых голосов, и можно создать свой: записать фразу своим (или любым другим) голосом, после чего синтезатор будет говорить любые предложения этим голосом.

## Запуск

Откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari). Устанавливать ничего не нужно.

Для записи с микрофона браузеру нужен «безопасный» адрес. Если микрофон не включается при открытии файла напрямую, запустите локальный сервер:

```bash
python3 -m http.server 8000
# и откройте http://localhost:8000
```

Можно также выложить папку на GitHub Pages: тогда страница будет доступна по https.

## Возможности

**Синтез речи**
- Любой русский текст: числа читаются прописью («366» → «триста шестьдесят шесть»), латиница транслитерируется.
- Интонация зависит от знаков препинания и слов: повествование, общий вопрос («Вы придёте?»), вопрос с вопросительным словом («Где ты был?»), сопоставительный вопрос («А ты?»), восклицание («Какая погода!»), незавершённость перед запятой.
- Ударение ставится автоматически. Его можно задать вручную: `зам+ок` или `зАмок`.
- Регуляторы скорости, высоты, выразительности интонации и громкости.
- График мелодики с отметками ударных слогов, показ ударений и фонетической транскрипции.
- Сохранение результата в WAV.

**5 системных голосов**

| Голос | Характер | Тон |
|---|---|---|
| Алексей | мужской, средний | 112 Гц |
| Мария | женский, мягкий | 205 Гц |
| Борис | низкий бас | 80 Гц |
| Ника | детский, звонкий | 285 Гц |
| Ольга | дикторский, спокойный | 175 Гц |

**Свой голос**: мастер из 4 шагов
1. «Вы в тихом месте?» Программа 3 секунды слушает тишину и измеряет фоновый шум. Если шумно, она предупредит.
2. Вы читаете длинную фразу (скороговорка-панграмма, вопрос и восклицание) своим или другим голосом. Вместо записи можно загрузить аудиофайл.
3. Вы протяжно произносите гласные «А — О — У — Э — И — Ы». Этот шаг можно пропустить.
4. Программа показывает отчёт о голосе. Дальше голос можно прослушать, дать ему название и сохранить. Он появится в списке голосов и будет озвучивать любой текст.

Голоса хранятся в браузере (localStorage), их можно экспортировать и импортировать в виде `.json`. Запись никуда не отправляется.

## Как это устроено (без ИИ)

| Модуль | Что делает |
|---|---|
| `js/g2p.js` | Текст → фонемы по правилам орфоэпии: ударение (словарь, суффиксные правила, «ё», разметка пользователя), аканье и иканье, мягкость, йотация, оглушение, ассимиляция по звонкости, «-ого» → [ова], «-тся» → [ца] и т. д. |
| `js/prosody.js` | Длительности, громкость и мелодика по интонационным конструкциям ИК-1…ИК-5, деклинация, фразовые акценты, предпаузальное удлинение. |
| `js/synth.js` | Формантный синтезатор по каскадно-параллельной схеме Клатта: голосовой источник (импульс Розенберга, джиттер, шиммер, придыхание), резонаторы F1–F6, носовой полюс и нуль, шумовые источники фрикативных и взрывных, вибрант «р», коартикуляция через локусы согласных. |
| `js/analyzer.js` | Анализ записи: шум, тон (YIN), форманты (LPC), наклон спектра, апериодичность, темп. Шкалы синтезатора подбираются «анализом через синтез»: синтезатор произносит ту же фразу, и параметры подгоняются, пока измерения не совпадут с записью. |
| `js/voices.js` | Системные голоса и хранилище пользовательских. |
| `js/dsp.js` | Резонаторы, БПФ, передискретизация, WAV. |

Модель голоса состоит из высоты и диапазона тона, форм речевого тракта (форманты гласных и их масштаб), тембра источника (наклон спектра, открытая фаза), придыхания, естественной нестабильности тона и темпа.
Это «портрет» голоса, а не побитовая копия: синтезированная речь звучит как этот человек по высоте, тембру, манере интонации и скорости, но остаётся формантным, немного «синтетическим» звучанием.

## Проверка

```bash
node tests/run.js
```

Тест проверяет разбор текста и ударения, форму интонации (подъём тона в вопросе, спад в повествовании), все 5 голосов и полный цикл клонирования. Цикл устроен так: синтезированную речь «записывают» (48 кГц с шумом), анализируют, и затем сверяют восстановленные высоту, форманты, темп и тембр с исходными.
