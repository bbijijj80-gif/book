Проекты и код.

## Проекты

- [`turret/`](turret/README.md) — автотурель на Raspberry Pi 4: слежение и
  автонаведение по USB-камере (детекция людей), поворот по азимуту на NEMA17
  через шаговый драйвер, наклон на сервоприводе, веб-интерфейс управления и
  Nerf-бластер на спуске с автоматическим выстрелом при захвате цели.
  Плюс отдельный физический пульт на ESP32 + дисплее Nextion —
  [`turret/remote/`](turret/remote/README.md).
