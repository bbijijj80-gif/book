# Экран Nextion — что собрать в Nextion Editor

Это не файл, который можно "загрузить" одной кнопкой — Nextion Editor
(бесплатная программа, только Windows; на Linux/Mac — через Wine) сам
компилирует ваш проект в `.tft`-файл. Ниже — точная спецификация, по которой
экран собирается руками за 10-15 минут. Скачать редактор: официальный сайт
Nextion (`nextion.tech`), раздел Download → Nextion Editor.

## 1. Новый проект

`File → New`, укажите модель дисплея. Если `NX1060P101-011C-1` не находится
в списке дословно — впишите/выберите модель с **тем же разрешением**, что
указано на наклейке на обратной стороне вашего экрана (скорее всего
1024×600 для 10.1", но проверьте по факту — от этого зависит только то, как
редактор рисует холст, на работу протокола не влияет).

## 2. Кнопки — 9 штук

Для КАЖДОЙ кнопки: перетащите компонент **Button** на страницу, затем в
панели атрибутов (Attribute, обычно справа) задайте:
- **objname** — как в таблице ниже (просто для вашего удобства при чтении проекта)
- **id** — **точно** число из таблицы (это то, по чему прошивка ESP32 узнаёт,
  какую кнопку нажали)
- **txt** — надпись на кнопке (латиницей — см. примечание про шрифты в конце файла)
- Вкладки **Touch Press Event** и **Touch Release Event** (обычно внизу
  панели атрибутов или отдельная вкладка "Event") — в ОБЕИХ включите
  галочку **"Send Component ID"**. Без этого прошивка не узнает ни о
  нажатии, ни об отпускании.

| objname | id | txt (надпись) | Назначение |
|---|---|---|---|
| b_arm | 1 | ARM | Взвод/снятие с взвода (первое нажатие — запрос подтверждения, второе в течение 3 сек — реальный взвод) |
| b_mode | 2 | MODE | Переключение AUTO / MANUAL |
| b_up | 3 | UP | Наклон вверх (работает, пока удерживаете) |
| b_down | 4 | DOWN | Наклон вниз (удержание) |
| b_left | 5 | LEFT | Поворот влево (удержание) |
| b_right | 6 | RIGHT | Поворот вправо (удержание) |
| b_center | 7 | CENTER | Возврат в центр |
| b_fire | 8 | FIRE | Ручной одиночный выстрел |
| b_estop | 9 | STOP | Аварийный останов — сделайте эту кнопку заметно крупнее и красным фоном (`pco`/`bco` в атрибутах) |

Расположение — на ваше усмотрение, но разумно: `b_up/b_down/b_left/b_right`
рядом друг с другом крестом (как джойстик из четырёх кнопок), `b_estop`
отдельно, крупно, там, где случайно не заденете пальцем остальные кнопки.

## 3. Текстовые поля — 8 штук

Компонент **Text**. Для этих `id` не важен (не переиспользуется прошивкой),
важен только `objname` — впишите **точно** как в таблице (регистр важен),
и начальный `txt` для красоты при первом включении.

| objname | начальный txt | Что показывает |
|---|---|---|
| t_status | SAFE | ARMED / SAFE / CONFIRM? |
| t_mode | MANUAL | AUTO / MANUAL |
| t_lock | - | LOCK, когда цель захвачена, иначе "-" |
| t_fps | 0 | FPS с камеры Pi |
| t_targets | 0 | Число найденных целей |
| t_pan | 0 | Позиция по азимуту (шагов от центра) |
| t_tilt | 0 | Угол наклона, градусы |
| t_conn | ... | Статус связи: WIFI..., WIFI OK, NET WIFI, NET PI, OK |

Крупным шрифтом и заметным цветом стоит сделать `t_status` — это главный
индикатор безопасности на пульте (аналог красной подсветки в браузерном
интерфейсе при ARMED).

## 4. Порт и скорость UART дисплея

`Program.s` (в дереве проекта слева, обычно уже открыт по умолчанию) или
через `Tools → Comm` — убедитесь, что baud rate выставлен **9600** (это
завод по умолчанию для Nextion). Если у вас он был изменён на что-то другое
— либо верните на 9600, либо поменяйте `NEXTION_BAUD` в прошивке ESP32 под
тот же baud, что стоит на экране (они должны совпадать один в один).

## 5. Компиляция и загрузка на экран

1. `File → Compile` (или кнопка с молотком) — получите файл `*.tft` в папке проекта.
2. Скопируйте этот `.tft` на microSD-карту (в корень, без вложенных папок).
3. Выключите питание дисплея, вставьте карту, включите питание.
4. Дисплей сам обнаружит файл на карте, спросит подтверждение и перепрошьётся
   (обычно занимает меньше минуты). После — выключите, выньте карту, включите
   уже без карты для обычной работы.

## О кириллице на экране

Прошивка ESP32 нарочно шлёт на экран только латинские подписи (ARMED, SAFE,
AUTO, MANUAL и т.п.) — как и оверлей "LOCK" на видео в веб-интерфейсе, это
не оплошность, а осознанный выбор: у Nextion свои встроенные шрифты, и без
явной генерации отдельного шрифта с кириллическими глифами (Tools → Font
Generator в редакторе, с явным добавлением диапазона Unicode для кириллицы)
русский текст рискует отобразиться пустыми квадратами. Если захотите
русские подписи — сначала сгенерируйте и прикрепите такой шрифт к каждому
компоненту в редакторе, потом можно менять `txt` в прошивке
(`esp32_nextion_remote.ino`, вызовы `nxSetText(...)`) на кириллицу — но это
отдельный, необязательный шаг, к надёжности протокола касаний/команд
отношения не имеющий.
