# 🧠 CPU AI Studio

Программа для Windows: создаёт и обучает языковую модель (GPT) **с нуля, только на процессоре** — видеокарта не нужна.

## Запуск
1. Установите Python 3.10+ (python.org, галочка *Add to PATH*).
2. Дважды щёлкните `run.bat` — при первом запуске он сам поставит CPU-версию PyTorch и остальное.
3. Хотите один `.exe`? Запустите `build_exe.bat`.

## Что умеет
- **Данные**: любой датасет с Hugging Face (`автор/название`, потоковая загрузка без скачивания гигабайтов), либо свой `.txt/.jsonl/.csv/.parquet`. Диалоговые форматы (alpaca, ultrachat, messages…) распознаются автоматически.
- **Модель**: пресеты и ползунки (слои, головы, ширина, контекст, словарь, dropout) с живым подсчётом параметров. Токенайзер BPE обучается под ваши данные.
- **Обучение**: ползунки шагов, батча, LR, разогрева, weight decay, обрезки градиента, числа потоков CPU; живой график loss, скорость, оставшееся время, пауза/стоп, автосохранение.
- **Чат**: диалог или продолжение текста; температура, top-k, top-p, штраф за повторы, длина.
- **Сохранение**: `.pt`, загрузка и дообучение, экспорт папкой (модель, токенайзер, `config.json`, `safetensors`, автономный `chat.py`).

## Советы
- Чтобы ИИ отвечал на вопросы, обучайте на диалоговом датасете (например `tatsu-lab/alpaca`); для связного текста — `roneneldan/TinyStories`.
- Для слабого ПК: пресет «Крошечная», контекст 128, потоков ≤ ядер. Модель в 5–20M параметров реально обучить за час-два.
- Модель с нуля умна ровно настолько, насколько велики модель, датасет и время обучения — это не ChatGPT, а ваш собственный маленький ИИ.
